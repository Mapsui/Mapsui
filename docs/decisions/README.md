# Decision records

One file per decision, numbered in order of acceptance: `0001-render-cache-ownership.md`. A record states the context, the decision and its consequences in a page or less. Once accepted it is not edited; a later decision that changes it gets its own record and names the one it supersedes.

Front matter:

```yaml
---
title: "0002: Short name"
status: proposed | accepted | superseded
---
```

Decisions that are rules from now on also appear in the architecture principles; the record keeps the reasoning at the time.
