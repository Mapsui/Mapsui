A map in your .NET app

An open source map component for .NET. Tile layers, vector styling, projections and touch handling, with the same API on every UI framework it supports.

Live samples Documentation

Background rendered by Mapsui at reduced opacity. Map data © OpenStreetMap contributors.

Works with every major .NET UI framework

Only the map control is platform-specific. The map, its layers and styles are the same code on all of them.

Get started with .NET MAUI

Add the package
dotnet add package Mapsui.Maui

Dependable

Developed in the open since 2012, and still actively maintained.

Every major version comes with a written upgrade guide, and the v4 documentation stays online. Breaking changes are announced in the roadmap before they land.

Built on libraries you already trust

SkiaSharp All drawing goes through Skia, so a map looks the same on every platform.
BruTile Tile sources, caching, WMTS and OpenStreetMap out of the box.
NetTopologySuite Real geometry: WKT, GeoJSON and spatial predicates, through Mapsui.Nts.
